# Цветочный магазин — тестовое задание

## Выполненные задачи

### 1. База данных (Room)
- Созданы таблицы:
    - `flowers` — 10 видов цветов с остатками (`stock`).
    - `bouquets` — готовые букеты (название, цена, описание).
    - `bouquet_flowers` — связь «букет → цветок» с количеством.
- Реализован **репозиторий** с методом покупки букета (транзакция, проверка остатков, списание цветов).
- При первом запуске база наполняется тестовыми данными.

### 2. Миграция БД (версия 1 → 2)
- Добавлены поля:
    - `country_of_origin` (страна-производитель) в таблицу `flowers`
    - `packaging_type` (оформление: крафтовая бумага, корзина и т.д.) в таблицу `bouquets`
- Написана миграция через `Migration`, старые записи обновлены значениями по умолчанию.

### 3. Interceptor для логирования кода ответа сервера
- Реализован `LoggingInterceptor` (OkHttp).
- Перехватывает и логирует код HTTP-ответа (например, 200 OK) при запросе к тестовому API.

### 4. Паттерны Builder и Abstract Factory
- Класс `Car` с полями: марка, модель, год, цвет, тип двигателя.
- Реализован **Builder** (пошаговое создание объекта).
- Реализована **Abstract Factory** (две фабрики: `SedanFactory`, `SportsCarFactory`).
